Changelog

Every CyberFoil release, newest first. You are looking at 1.5.0.

1.5.0

13 October 2026

Themes

  • JSON themes in switch/CyberFoil/theme/ - colors, background, banner, and UI icons.
  • Settings → System → Theme applies a palette immediately, with a progress screen while layouts recreate.
  • Default restores the built-in look without deleting files. Selection stored as themeFile.
  • Bundled palettes: Midnight Blue, OLED Mint, Forest Green, Violet Dusk, Ember Amber, Crimson Night.
  • Tinfoil theme JSON needs adapting to CyberFoil schema version 1.

Offline database

  • Optional custom_titles.pack and custom_icons.pack. Matching title IDs use the custom entry.
  • Build packs with tools/create_custom_packs.py. Icons are 128×128 WebP (quality 80, method 6).
  • Database updates leave custom packs in place.

USB browsing

  • Hidden by default: dot files, macOS ._ sidecars, $RECYCLE.BIN, System Volume Information.
  • − or Show hidden / Hide hidden toggles visibility. Preference saved in General settings.
  • Hidden entries stay out of Select All and new install selections.

Remote and installs

  • Discover AeroFoil servers on the LAN from Remote settings.
  • Separate LAN and Remote addresses, with LAN-first automatic selection or a forced endpoint.
  • Installs run on a worker. The screen shows the active title and pending queue.
  • Add or remove pending titles during Remote and local-file installs.
  • B cancels the active title and the rest of the batch. Completed titles stay.
  • X blanks the screen while the install continues. Any button or touch wakes it.

1.4.6

18 August 2026

New

  • AeroFoil cheat manager in Remote: browse, download, install, view, create, edit, delete, and upload.
  • Remote titles grouped by base game, update, and DLC.
  • Remote editor redesigned as a themed modal.

Improvements

  • Better compatibility with legacy remotes, including custom headers and nested directory indexes.
  • More robust Remote lists and legacy title loading.
  • Clean shutdown when leaving from the homebrew launcher.

Fixes

  • HTTP range failures report a real diagnostic instead of a generic error.
  • Timeouts and retries for stalled network installs.
  • Credentials sent only to the configured server origin.
  • UAUTH generation when a server uses its default port.

1.4.5

2 June 2026

Highlights

  • Initial offline JSON database support.
  • Migration from the previous offline-DB folder layout.
  • Docked input: all controller slots, HDMI dock usage fixed.
  • Firmware mismatch note updated.

Fixes

  • Save-data fix and locale refresh.
  • Date sorting for legacy connection and DLC sections.
  • Korean language selection text where glyphs were missing.
  • Compilation warnings cleaned up. Install chatter removed.

1.4.4

18 April 2026

Highlights

  • Staged shop loading with clearer status and animated feedback.
  • In-memory shop catalog cache - reopening does not re-download unless refresh or config changed.
  • Legacy / Tinfoil shop compatibility and encrypted shop support.

Fixes

  • IPC handle exhaustion when installing XCI from shop.
  • Unresponsive buttons in some cases. Input refreshed after the software keyboard closes.
  • MTP completed-install back action. Shop list-mode selection icon.

1.4.3

8 April 2026

Highlights

  • NCZ block support for installs.
  • Faster shop loading for large lists. List/grid toggle, refresh, and checkbox state fixes.
  • Browse sorting. Search and sort controls split.
  • Held-navigation feedback. Image-fetch status visibility.

Networking

  • UAUTH generation updated to the current auth spec.
  • Shop path support with config migration. Custom shop ports preserved when editing.
  • Legacy shop cache removed.

Diagnostics

  • File-based debug logging and verbose install diagnostics in Options.

1.4.2

15 March 2026

Shop

  • Faster shop startup on consoles with many installed titles.
  • Lazy loading for the Installed section.
  • Non-blocking icon fetch. Offline icons first, then shop icon URL.

Network

  • JBOD URL parsing and segmented downloads.
  • HTTP range retry and resume. Basic auth for network downloads.
  • Unified outbound User-Agent. Default remains cyberfoil.

Offline DB and updates

  • Faster offline DB updates with buffering and parallel ranged downloads.
  • Fallback to a single stream when ranged downloads are not suitable.
  • In-app changelog viewer on the update prompt, paged for long notes.
  • Install screen dims after inactivity; touch restores brightness.
