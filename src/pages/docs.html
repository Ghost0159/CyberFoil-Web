Supported formats

  • NSP / NSZ - Nintendo Submission Package (compressed)
  • XCI / XCZ - cartridge image (compressed)

On the network, the extension is ignored: CyberFoil looks at the bytes, not the name.

Remote profiles

One JSON file per host, under sdmc:/switch/CyberFoil/remotes/. Settings → Remote can Discover LAN Servers (UDP 8465, payload OWNFOIL_DISCOVER).

{
  "remote": {
    "protocol": "http",
    "host": "192.168.1.2",
    "path": "",
    "port": 8465,
    "username": "user",
    "password": "pass",
    "title": "My LAN remote",
    "favourite": false,
    "legacyMode": false,
    "lanUrl": "http://192.168.1.2:8465",
    "wanUrl": "https://remote.example.com",
    "connection": "auto",
    "uid": ""
  }
}
  • connection: auto (LAN first, ~2 s probe), lan, or wan
  • WAN URL is always HTTPS. LAN protocol is HTTP or HTTPS. Address fields with no port use HTTP 80 or HTTPS 443; AeroFoil's usual LAN listen port is 8465
  • uid from discovery lets a later scan update the same profile. Credentials are never taken from discovery.
  • Auth and catalog errors do not flip LAN ↔ WAN. The chosen endpoint stays fixed until you reopen Remote or refresh the catalog.

External themes

Copy .json files into theme/, or a folder such as theme/my-theme/theme.json with images beside it. Settings → System → Theme. A applies immediately; Default clears themeFile without deleting files. 

{
  "version": 1,
  "enabled": true,
  "name": "My Theme",
  "colors": {
    "background": "#101827",
    "text": "#EAF2FFFF",
    "selected_text": "#FFFFFFFF",
    "accent": "#56A8FFFF",
    "highlight": "#245F9DCC"
  },
  "images": {
    "background": "background.png",
    "logo": "banner.png"
  }
}
  • Colors: #RRGGBB or #RRGGBBAA. Roles: background, header, footer, panel, text, selected_text, muted_text, accent, highlight, scrollbar, progress_track.
  • Background 1280×720, banner 480×93. PNG / JPEG / WebP, max 16 MiB and 4096 px per side. JSON max 256 KiB.
  • Image keys match romfs/images/ paths. "background": "" disables the background image.
  • Malformed JSON or an unsupported version falls back to Default. Theme apply waits until an active install finishes.

Offline database

Title names and icons under offline_db/ - used when Remote/network metadata is unavailable. Default manifest: CyberFoil-DB releases. Packed or JSON layouts (titles.pack, icons.pack, index files, etc.).

Custom packs: put custom_titles.pack and/or custom_icons.pack in the same folder. Same binary format as the defaults; custom IDs win. Restart after replacing them by hand. Generate with python tools/create_custom_packs.py --titles my_titles.json --icons-dir my_icons --output custom_packs (Python 3.8+, Pillow ≥ 9.1 for images).

Install controls

  • Worker thread does the transfer; the UI polls input and renders on its own.
  • Active-title card + six pending rows. ↑/↓ select, ←/→ page, A drop a pending title.
  • Y Add titles on Remote and SD/USB (current folder). PC USB / net / MTP batches stay host-controlled.
  • B cancels the active title and remaining queue. Completed titles and their records stay.
  • X blanks the handheld screen. Any input wakes it; wake does not press a control.

Network install (LAN)

Separate from the HTTP Remote API. CyberFoil listens on TCP port 2000 while the net install screen is open.

  1. Launch Install over LAN or internet - your Switch IP is shown.
  2. On PC/phone, use NS-USBloader (Tinfoil mode) or similar: target that IP, send file list.
  3. Alternatively pick URL or Google Drive file ID from the menu.

Downloads use the configured User-Agent (cyberfoil by default), not the empty UA from legacy Remote mode.
