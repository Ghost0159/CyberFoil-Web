1.5.0

13 October 2026

Themes

  • JSON themes in switch/CyberFoil/theme/ - colors, background, banner, and UI icons.
  • Settings → System → Theme applies a palette immediately, with a progress screen while layouts recreate.
  • Default restores the built-in look without deleting files. Selection stored as themeFile.
  • Bundled palettes: Midnight Blue, OLED Mint, Forest Green, Violet Dusk, Ember Amber, Crimson Night.
  • Tinfoil theme JSON needs adapting to CyberFoil schema version 1.

Offline database

  • Optional custom_titles.pack and custom_icons.pack. Matching title IDs use the custom entry.
  • Build packs with tools/create_custom_packs.py. Icons are 128×128 WebP (quality 80, method 6).
  • Database updates leave custom packs in place.

USB browsing

  • Hidden by default: dot files, macOS ._ sidecars, $RECYCLE.BIN, System Volume Information.
  • − or Show hidden / Hide hidden toggles visibility. Preference saved in General settings.
  • Hidden entries stay out of Select All and new install selections.

Remote and installs

  • Discover AeroFoil servers on the LAN from Remote settings.
  • Separate LAN and Remote addresses, with LAN-first automatic selection or a forced endpoint.
  • Installs run on a worker. The screen shows the active title and pending queue.
  • Add or remove pending titles during Remote and local-file installs.
  • B cancels the active title and the rest of the batch. Completed titles stay.
  • X blanks the screen while the install continues. Any button or touch wakes it.

1.4.6

18 August 2026

New

  • AeroFoil cheat manager in Remote: browse, download, install, view, create, edit, delete, and upload.
  • Remote titles grouped by base game, update, and DLC.
  • Remote editor redesigned as a themed modal.

Improvements

  • Better compatibility with legacy remotes, including custom headers and nested directory indexes.
  • More robust Remote lists and legacy title loading.
  • Clean shutdown when leaving from the homebrew launcher.

Fixes

  • HTTP range failures report a real diagnostic instead of a generic error.
  • Timeouts and retries for stalled network installs.
  • Credentials sent only to the configured server origin.
  • UAUTH generation when a server uses its default port.
