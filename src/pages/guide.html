Get CyberFoil onto your Switch

If Atmosphere (or another CFW) and the homebrew menu are already there, you are four steps from a first install.

  1. Grab the zip

    Download cyberfoil.zip from GitHub releases. Extract it: the file that matters is switch/CyberFoil/cyberfoil.nro. Example themes land in switch/CyberFoil/theme/. They sit quietly until you pick one.

  2. Copy it to the SD card

    Drop the whole CyberFoil folder under switch/ so you end up with sdmc:/switch/CyberFoil/cyberfoil.nro. An existing config.json, Remote profiles, and custom offline packs stay put.

  3. Launch it

    Open the homebrew menu (hold R on a game, or whatever you already use) and run CyberFoil. Applet mode works. If something feels tight on memory, switch to full memory mode.

  4. Install something

    Pick a source on the main grid: SD card is the friendliest first try. Select files, press +, choose SD or internal storage, wait. The install screen stays interactive: add or drop pending titles, press B to cancel the rest, or X to blank the screen.

Remote server. Settings → Remote. Discover AeroFoil hosts on the LAN (UDP 8465), or type a LAN address and an optional WAN address. Profiles live under remotes/. Older shops/*.json files migrate on their own. The Remote API page lists what your server has to return.
Theme. Settings → System → Theme. Stay on Default, or try a bundled palette (Midnight Blue, OLED Mint, Forest Green, Violet Dusk, Ember Amber, Crimson Night). A Tinfoil theme JSON is not drop-in: reshape it to CyberFoil's schema in the docs.
Saves and cheats. Save backup uploads every file for one user and asks for a note. Cheats install into Atmosphere's contents folder. Both need an AeroFoil-compatible server, and both stay off in Tinfoil / legacy mode.
