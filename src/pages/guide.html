Installation guide

Assumes you already have homebrew set up (Atmosphere or similar).

  1. Get the files

    Download cyberfoil.zip from GitHub releases. Extract it - you want switch/CyberFoil/cyberfoil.nro.

  2. Copy to SD

    Put the whole CyberFoil folder under switch/ on your SD card: sdmc:/switch/CyberFoil/cyberfoil.nro

  3. Launch

    Open the homebrew menu (hold R on a game, or your usual method) and run CyberFoil. Applet mode works but full memory mode is recommended if you hit issues.

  4. Install something

    Pick a source on the main grid - SD card is the simplest to start with. Select files, press +, choose SD or internal storage, wait.

Shop server: Set URL in Settings (e.g. http://192.168.1.2:8465) or save profiles under shops/. See the Shop API page for what your server must return.
Save backup: Uploads all saves for one user to the shop server with a required note. Needs AeroFoil-compatible /api/saves/* endpoints (disabled in Tinfoil/legacy mode).
