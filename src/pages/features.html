What CyberFoil can do

Every tile on the main grid is another way to get files onto the Switch. Same install flow, same queue, same destination: pick the source that matches how you already work.

  • SD card

    Copy NSP, NSZ, XCI, or XCZ onto the microSD, browse, select, press +. You can delete the originals after. Mid-batch, you can still add more files from the folder you are in.

  • LAN / Internet

    While net install is open, CyberFoil listens on TCP port 2000. Point NS-USBloader (Tinfoil mode) at the Switch IP on screen, or paste a direct URL / Google Drive file ID.

  • Remote

    An HTTP catalog on the LAN or over the internet (port 8465 by default). Discover AeroFoil hosts nearby, keep a LAN and a WAN address, and pick Auto / LAN / WAN. Sections, local search, update and DLC prompts, icon cache. The API reference is the full contract.

  • USB (NS-USBloader)

    Install from a PC over USB. It works, but it can be picky depending on the cable and the host. LAN is often the calmer route.

  • USB SSD / HDD

    Plug in an external drive. FAT, NTFS, and EXT via libusbhsfs: same picker as the SD card. Dot files, macOS ._ sidecars, and Windows metadata folders stay hidden unless you press −.

  • MTP

    The PC sees an MTP folder over USB. Drop files there and they install. Choose SD or internal storage as the target first.

  • Save backup

    Upload every local save for one user to your Remote server, with a short note so you can tell versions apart. Needs an AeroFoil-compatible backend.

  • Cheats

    Browse AeroFoil cheat sections, install one build or all of them, then view, edit, delete, or upload the local files. They land in atmosphere/contents/<titleId>/cheats/<buildId>.txt.

  • Offline DB

    Title names and icons live in offline_db/ on the SD card. When you are online, CyberFoil can check CyberFoil-DB on startup. Optional custom_titles.pack / custom_icons.pack override matching title IDs and survive those updates.

  • Themes

    JSON palettes in theme/: colors, background, banner, and UI icons. Six examples ship in the zip. Pick one in Settings → System → Theme; it applies immediately, no restart.

  • Install queue

    Transfers run on a worker so the UI stays awake. You see the active title and the pending rows. Add or drop titles mid-batch on Remote and local files. B cancels the rest; X blanks the screen.

  • Settings

    NCA verification, boost mode, language, Remote profiles, Tinfoil mode, hidden USB files, offline DB updates, auto-update: all from the main grid → Settings.
