HTTP streaming download

Remote installs stream into NCM placeholders: the full file is not parked on the SD card first.

  • Range: offset-(offset+size-1) → HTTP 206
  • Accept-Encoding: identity
  • 3 retries / segment, 2 s delay; timeouts plus a user retry dialog after exhaustion
  • NSP vs XCI: bytes 0x100-0x103 == HEAD → XCI, else NSP

Install requests may add Tinfoil headers (Theme, UID, HAUTH, UAUTH, …) plus HTTP Basic when configured. Basic auth is sent only to the configured origin.

LAN protocol - port 2000

  1. Client → <switch-ip>:2000
  2. Receive u32 size, then payload (newline-separated URLs, max ~262 KB)
  3. Each URL installed via HTTP range
  4. Done: 1-byte 0x00 ack + HTTP DROP to host

Y on net screen: manual URL or Google Drive ID.

USB protocol

TUL0 - title list (magic 0x304C5554). TUC0 - file range commands, 8 MB bulk reads.

XCI if title name ends with xc.

Local & MTP

Extensions .nsp .nsz .xci .xcz. SD/HDD: 4 MB sequential reads. MTP: incremental parse on upload to install/.

USB volumes hide dot files and Windows metadata names unless usbHddShowHiddenFiles is on.

LAN Remote discovery

Separate from TCP :2000. Settings → Remote broadcasts UDP 8465 with OWNFOIL_DISCOVER and lists AeroFoil replies (name, IPv4, HTTP port, version, public/private).

Auto connection probes the LAN URL (~2 s) then uses WAN. Auth/catalog errors do not switch endpoints. Details: Remote API.
